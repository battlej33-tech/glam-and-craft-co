# GLAM & CRAFT CO. — GitHub Pages starter site

This is a responsive static website starter based on the approved design direction: pink leopard accents, black, baby pink, cream, gold, bows, subtle sparkle, elegant serif headings, and a Black beauty editorial image.

## Files
- `index.html` — home page
- `styles.css` — colors, layout, responsive design, dark mode styling
- `script.js` — mobile menu, dark mode, back-to-top, demo form feedback
- `winter-christmas.html`, `fall-halloween.html`, `summer-floral.html`, `3d-nails.html`, `y2k.html`, `mcbling.html`, `custom-nails.html`, `other-styles.html` — separate collection pages
- `custom-orders.html`, `about.html`, `contact.html`, `faq.html`, `care.html`, `shipping-returns.html`
- `assets/design-preview.png` — visual concept preview
- `assets/hero-editorial.jpg` — generated hero editorial crop

## Before publishing
1. Replace the “Add your nail photo” placeholders on each collection page with your own original nail photos. The exact six nail photos previously selected were not available in this file package, so they have not been substituted with invented nail photos.
2. Add real design names, short descriptions, confirmed individual prices, nail shapes, lengths, and customization options.
3. Create a business-only email with your parent/manager's help, then connect the order form to a trusted form service or approved business email. The current form is a front-end demo and does not transmit or store customer orders.
4. Add social media links only after the accounts and manager are ready.
5. Confirm shipping, returns, and delivery policies before publishing them as final business policies.

## Add to GitHub Pages
1. Download and unzip this folder.
2. Open your GitHub repository.
3. Upload the contents of this folder (not the outer folder itself) to the repository's main/root branch.
4. If GitHub asks, choose to replace the existing `index.html`, `styles.css`, and `script.js` only after keeping a backup of the old site.
5. In the repository, open **Settings → Pages** and set deployment to the main branch and `/ (root)` if it is not already configured.
6. Wait for GitHub Pages to publish, then refresh your website link.

This package does not directly change your GitHub repository or publish the site. You must upload the files to GitHub. Keep your personal email, home address, school, and other private details off the public website.
